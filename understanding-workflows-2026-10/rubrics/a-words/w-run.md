# Rubric: Run

If the learner misses a question here, set a DEFINE or INTERPRET move for run live, as help (it is
recorded as helped and doesn't count), then come back to a production question.

A run is one execution of a workflow, from its trigger to an outcome: this applicant, this order,
this Tuesday. The workflow is the arrangement every run follows. "Instance" is another name for a
run, not a confusable.

### vs-workflow

- **goal:** `w-run`
- **move:** DISTINGUISH
- **answer:** The workflow is the adoption process in the diagram, the arrangement every
  application goes through. A run is one pass through it, such as the Lopez family's application
  for Rosie. Last month there were fourteen runs of the one workflow.
- **credit:** full for naming that the workflow is the arrangement and a run is one execution of
  it; the Lopez application as the example is not required, but any example given must be matched
  correctly, and a mismatched one makes it half. None for an incidental difference alone, such as
  that a run has a date or that the workflow is written down.

### catch-name

- **goal:** `w-run`
- **move:** CATCH
- **answer:** What she drew up and has used for every new tutor is the workflow, not a run. A run
  is one execution of it: onboarding one particular tutor, once.
- **credit:** full for naming that she is describing the workflow and that a run is one pass
  through it for one tutor. Half for "that's the workflow" with nothing on what a run would be.
  None for a different quibble alone, such as that five steps is too few or that the drawing is
  out of date.

### catch-pick

- **goal:** `w-run`
- **move:** CATCH
- **type:** mcq
- **answer:** 4
- **credit:** full for 4 only. Maria's rental is one execution of the workflow, from its start to
  its end. Choice 1 reads run as the workflow: what the shop changed is the arrangement every
  rental follows. Choice 2 reads run as one step of the workflow. Choice 3 stretches run to a
  day: each rental is its own run, so Saturday held thirty-two of them.
