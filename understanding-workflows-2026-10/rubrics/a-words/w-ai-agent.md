# Rubric: AI agent

If the learner misses a question here, set a DEFINE or INTERPRET move for AI agent live, as help
(it is recorded as helped and doesn't count), then come back to a production question.

An AI agent is the kind of executor that brings judgment to a step. A skill is instructions, a
file the agent follows. What separates them is that the agent's judgment reaches past what the
file says: where the file doesn't settle a case, the agent decides it anyway. "Bot" is another
name for an AI agent, not a confusable. Everyday shorthand that gives the skill credit ("the skill
sorts the volunteers") is fine and is not a misuse; the misuse is treating the agent as the file,
so that nothing it does could go beyond what the file says.

### vs-skill

- **goal:** `w-ai-agent`
- **move:** DISTINGUISH
- **answer:** The skill is the instructions, the file saying how to sort. The AI agent is what
  carries them out, and it brings judgment the file doesn't contain: nothing in the file covers
  coaching, so placing the soccer coach in Tutoring was the agent's own call.
- **credit:** full for naming that the skill is instructions and the AI agent is the executor that
  brings judgment beyond them; the coaching placement as the example is welcome but not required.
  Half for "the skill is a file and the agent is the program that runs it" with nothing on
  judgment. None for an incidental difference alone, such as that the skill is written in plain
  English.

### catch-search

- **goal:** `w-ai-agent`
- **move:** CATCH
- **answer:** An AI agent brings judgment beyond what its skill file says, so the refund need not
  be in the file at all. The file covers damaged items; deciding that a different shade of blue
  counts as damage was the agent's own call, and searching the file won't find it.
- **credit:** full for naming that an AI agent brings judgment of its own beyond the file, so the
  refund came from the agent's reading of "damaged" and not from a line in the file. Half for
  "the agent misread the file" with nothing on the agent bringing judgment the file doesn't
  contain. None for a different quibble alone, such as that the shop should never refund for a
  color difference.

### catch-pick

- **goal:** `w-ai-agent`
- **move:** CATCH
- **type:** mcq
- **answer:** 4
- **credit:** full for 4 only. The file covers classes, the meeting wasn't one, and leaving it open
  was the agent's judgment. Choice 1 reads the agent as its skill, but what it did isn't in the
  file. Choice 2 reads the agent as a script; no exact rule covered an optional meeting. Choice 3
  stretches the word to a calendar, which holds information and carries out no step.
