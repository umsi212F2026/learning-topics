# Rubric: Trigger

If the learner misses a question here, set a DEFINE or INTERPRET move for trigger live, as help (it
is recorded as helped and doesn't count), then come back to a production question.

A trigger is the condition a run starts from: something now holds (a request has arrived, a date
has come), and a run begins. It is not the first thing done in the run; that is a step. "Start
state" and "start event" are other names for it, not confusables.

### vs-step

- **goal:** `w-trigger`
- **move:** DISTINGUISH
- **answer:** The trigger, "Reset request received", is a condition: a request has come in, and
  that starts a run. Nobody does it. A step is an action someone takes during the run, such as
  the technician verifying the caller's identity. Even the first step is a step, not the trigger.
- **credit:** full for naming that the trigger is the condition a run starts from and a step is an
  action taken in the run; examples are not required, but any given must be matched correctly, and
  calling "Verify the caller's identity" the trigger makes it a miss. Half for "the trigger comes
  first and steps come after" with nothing on condition versus action. None for an incidental
  difference alone, such as their shapes on the diagram.

### catch-pick

- **goal:** `w-trigger`
- **move:** CATCH
- **type:** mcq
- **answer:** 2
- **credit:** full for 2 only. A request arriving is the condition a run starts from. Choice 1 is
  the first step, an action. Choice 3 is the outcome, the condition at the end of a run. Choice 4
  is an actor who carries out steps, not a condition at all.
- **tutor note:** a learner who picks 1 is reading the trigger as the first thing done; ask what
  has to be true before the librarian has anything to search for.

### catch-payroll

- **goal:** `w-trigger`
- **move:** CATCH
- **answer:** Exporting the timesheets is the first step, an action the clerk takes inside the
  run. The trigger is the condition the run starts from: the last business day of the month has
  arrived. The run has already started by the time the clerk exports anything.
- **credit:** full for naming that exporting is a step (an action) and the trigger is the
  condition the run starts from; naming the last business day as that condition is welcome but
  not required. Half for "the trigger is the date" with nothing on why exporting isn't one. None
  for a different quibble alone, such as that the accountant should export the timesheets.
