# Rubric: Script

If the learner misses a question here, set a DEFINE or INTERPRET move for script live, as help (it
is recorded as helped and doesn't count), then come back to a production question.

A script is instructions a computer follows exactly, with no judgment: given the same input, it
does the same thing every time, and it does only what is written. An AI agent brings judgment to a
step. "Program", "code" and "executable" are other names for a script, not confusables.

### vs-ai-agent

- **goal:** `w-script`
- **move:** DISTINGUISH
- **answer:** The script follows its instructions exactly, with no judgment: any row with no date
  is deleted, every time. The AI agent brings judgment: whether a comment "seems to describe" an
  equipment problem is a call it has to make, row by row.
- **credit:** full for naming that the script does exactly what it says with no judgment and the
  AI agent brings judgment; matching them to the lab's two steps is not required, but any match
  given must be right. Half for "the script is code and the agent is AI" with nothing on
  judgment. None for an incidental difference alone, such as that the script is faster or
  cheaper.

### catch-decided

- **goal:** `w-script`
- **move:** CATCH
- **answer:** A script doesn't decide anything or judge whether a change looks small: it follows
  its instructions exactly. If the tests were skipped, either its instructions say to skip them
  under some condition that held, or a person or something else made that call, not the script.
- **credit:** full for naming that a script brings no judgment, so it cannot have decided the
  change looked small; saying where the skip must have come from instead is welcome but not
  required. Half for "scripts can't think" with nothing tying it to this skip. None for a
  different quibble alone, such as that tests should never be skipped.

### catch-pick

- **goal:** `w-script`
- **move:** CATCH
- **type:** mcq
- **answer:** 2
- **credit:** full for 2 only. A script follows its instructions exactly, so a case they don't
  cover breaks it rather than calling for a choice. Choice 1 credits the script with judgment it
  doesn't have. Choice 3 reads the script as its confusable: running on a schedule is not
  judgment. Choice 4 stretches the word to the owner, who reads the email with her own judgment.
