# Rubric: Control flow

If the learner misses a question here, set a DEFINE or INTERPRET move for control flow live, as
help (it is recorded as helped and doesn't count), then come back to a production question.

Control flow is which step runs next: the order a run moves through, shown by the solid arrows. It
is not an action, and it is not data moving: data one step writes and another reads is data flow,
the dotted lines. Control flow is there whoever does the steps; an arrow inside one lane is
control flow just as much as one that crosses lanes (which is also a handoff). "Sequence flow" is
another name for it, not a confusable.

### vs-step

- **goal:** `w-control-flow`
- **move:** DISTINGUISH
- **answer:** A workflow step is an action someone takes, such as weighing the pet or examining
  it. Control flow is not an action; it is the order between steps, the solid arrows saying which
  step runs next: after "Weigh the pet" comes "Take the history", then "Examine the pet".
- **credit:** full for naming that a step is an action and control flow is which step runs next
  (the order the run moves through). Half for the right difference with control flow described
  only as "the arrows that connect the steps", with nothing on what they say. None for an
  incidental difference alone, such as that steps are boxes and control flow is lines.

### catch-carries

- **goal:** `w-control-flow`
- **move:** CATCH
- **answer:** The solid arrow does not carry the draft; it says that "Review the contract" runs
  next. The draft reaching the lawyer is data flow, the dotted lines through the "Contract draft"
  file, which the paralegal's step writes and the lawyer's step reads.
- **credit:** full for naming that control flow says which step runs next, and the draft moving is
  data flow (the dotted lines). Half for "the dotted lines carry the draft" with nothing on what
  the solid arrow says. None for a different quibble alone, such as that the lawyer should draft
  the contract.

### catch-pick

- **goal:** `w-control-flow`
- **move:** CATCH
- **type:** mcq
- **answer:** 2
- **credit:** full for 2 only. The solid arrow labeled "no" says which step runs next on that
  answer. Choice 1 calls a step control flow; "Fit the parts" is an action the arrows lead to.
  Choice 3 reads a dotted line as control flow; it says the step reads the repair notes, not that
  the run goes anywhere. Choice 4 reads control flow as a handoff; the arrows between the
  mechanic's own steps are control flow even though nothing changes hands.
