# Rubric: Workflow state

If the learner misses a question here, set a DEFINE or INTERPRET move for workflow state live, as
help (it is recorded as helped and doesn't count), then come back to a production question.

A workflow state is a condition that holds, such as "Appointment booked": something is now true.
A step is an action that happens, such as "Send a reminder text": someone does it. Triggers and
outcomes are states. "Event" is another name for a state on a diagram, not a confusable.

### vs-step

- **goal:** `w-workflow-state`
- **move:** DISTINGUISH
- **answer:** A state is a condition that holds: "Appointment booked", "Appointment confirmed" and
  "Visit complete" each say something is now true. A step is an action someone takes: "Send a
  reminder text" and "Clean the patient's teeth" are things the staff do.
- **credit:** full for naming that a state is a condition that holds and a step is an action that
  happens; sorting the diagram's five labels is not required, but any sorted must be sorted
  correctly, and one wrong makes it half. None for an incidental difference alone, such as that
  steps take longer or are drawn as a different shape.

### catch-pick

- **goal:** `w-workflow-state`
- **move:** CATCH
- **type:** mcq
- **answer:** 4
- **credit:** full for 4 only. "Bike ready for pickup" is a condition that holds once the run gets
  there. Choice 1 is a step, an action, however long it takes. Choice 2 is a gateway, where the flow
  divides. Choice 3 is a lane, which says whose job a step is.
- **tutor note:** a learner who picks 1 may be reading "state" as "where the bike is right now";
  ask what the mechanic is doing during it, and whether something that is being done can be a
  condition that holds.

### catch-call

- **goal:** `w-workflow-state`
- **move:** CATCH
- **answer:** Calling the owner is an action the receptionist takes, so it is a step, not a state.
  A state is a condition that holds, such as "Patient in recovery" or "Patient discharged"; how
  long the call lasts doesn't turn the action into a condition.
- **credit:** full for naming that "Call the owner" is an action (a step) and a state is a
  condition that holds. Half for "it's a step" with nothing on what a state is. None for a
  different quibble alone, such as that a nurse, not the receptionist, should call the owner.
