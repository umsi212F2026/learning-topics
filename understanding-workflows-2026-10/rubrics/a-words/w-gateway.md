# Rubric: Gateway

If the learner misses a question here, set a DEFINE or INTERPRET move for gateway live, as help (it
is recorded as helped and doesn't count), then come back to a production question.

A gateway is the place where the flow divides, or where divided paths come back together. It is
drawn as a diamond: one labeled with a question where the flow divides, usually an unlabeled one
where it merges. It is not an action. The checking or deciding that settles which way a run goes
is done in a step before the gateway; the gateway only routes the run on the answer.

### vs-step

- **goal:** `w-gateway`
- **move:** DISTINGUISH
- **answer:** A step is an action someone takes: the technician checking the file, or fixing it. A
  gateway is not an action; it is where the flow divides ("File print-ready?" sends a run one way
  or the other) or comes back together (the unlabeled diamond before printing). The checking
  happens in the step before; the gateway routes on its answer.
- **credit:** full for naming that a gateway is where the flow divides or rejoins and a step is an
  action someone takes; mentioning the merging diamond is welcome but not required. Half for the
  right difference with the checking placed in the gateway ("File print-ready?" is where the
  technician checks the file). None for an incidental difference alone, such as their shapes.

### catch-check

- **goal:** `w-gateway`
- **move:** CATCH
- **answer:** Comparing the invoice with the order is an action, so it is a step, not a gateway.
  The gateway "Invoice matches order?" does no work: it is where the flow divides, sending the run
  one way if they match and another if they don't, on the answer the comparing step produced.
- **credit:** full for naming that comparing is a step's action and the gateway is only where the
  flow divides on its result. Half for "that's a step" with nothing on what the gateway does.
  None for a different quibble alone, such as that a manager, not a clerk, should compare them.

### catch-pick

- **goal:** `w-gateway`
- **move:** CATCH
- **type:** mcq
- **answer:** 4
- **credit:** full for 4 only. A gateway is where the flow divides or comes back together, and the
  unlabeled diamond is where it comes back together. Choice 1 puts the checking in the gateway;
  looking through the calendar is the step before it. Choice 2 calls that step a gateway because
  its result routes the run, but the routing happens at the diamond after it. Choice 3 forgets
  that a gateway can merge as well as divide.
