# Data flow

### vs-control-flow

A middle school has drawn its workflow for a field trip. A teacher does "Collect permission
slips", which has a dotted line to a "Slip list" file and a solid arrow to "Book the bus". A solid
arrow leads on to "Send the packing list", and then to "Take attendance on the day", which has a
dotted line from the "Slip list" file.

In this diagram, what is the difference between data flow and control flow? Answer in two or
three sentences, in your own words.

### catch-run-moves

A tutoring center has drawn its workflow for marking a practice test. A tutor does "Mark the
test", which has a dotted line to a "Gradebook" file and a solid arrow to "Email the student". A
new tutor, describing the diagram, says:

"The data flow from 'Mark the test' to the gradebook means that once the test is marked, the run
goes on to the gradebook next."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A food bank has drawn its workflow for a donation. A volunteer does "Weigh the donation", which
has a dotted line to a "Stock sheet" file and a solid arrow to "Log the donor", which has a dotted
line to a "Donor list" file. On Friday a coordinator does "Plan the week's boxes", which has a
dotted line from the "Stock sheet" file. At the end of each month the coordinator does "Send
thank-you notes", which has a dotted line from the "Donor list" file.

Which of these statements uses the term "data flow" correctly?

1. The dotted line into the stock sheet says the run moves to the stock sheet after weighing.
2. The donor list is no data flow, since the step reading it runs weeks after it was written.
3. Weighing writes the stock sheet that planning the boxes reads later: that is data flow.
4. The arrow from weighing to "Log the donor" is data flow: the donation's details pass along it.
