# Skill

### vs-script

A small nonprofit puts photos in its monthly newsletter, using two files of instructions. The
first, "resize-photos.sh", is a script: it shrinks every photo to 800 pixels wide. The second,
"write-captions.md", is a skill: it tells an AI agent, "Write a friendly one-line caption for
each photo, naming anyone the photo's notes name." This month one photo came with no notes, and
the agent wrote a caption describing the scene instead.

In this situation, what is the difference between a skill and a script? Answer in two or three
sentences, in your own words.

### vs-prompt

A bookstore's AI agent drafts the store's newsletter every Monday. Each time, it reads a file,
"newsletter.md", which says: "Lead with the new arrivals, list the week's events, and keep it
under 300 words." This Monday the owner also typed a message to the agent before it started:
"Mention that the author signing on Saturday is sold out."

In this situation, what is the difference between a skill and a prompt? Answer in two or three
sentences, in your own words.

### catch-exact

A town museum has 4,000 scanned photos to rename, each to its catalog number followed by the year,
exactly as written on a list. The archivist writes a skill file that spells out the pattern and
plans to hand it to the museum's AI agent overnight. She tells a coworker:

"A skill runs exactly as it's written, like any code, so every file will come out in the pattern
and there will be nothing to check in the morning."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

An open-source project used to have one maintainer sort its new issues by hand. Now an AI agent
sorts them, following a skill file, "triage.md", that says: "Label bug reports 'bug' and feature
requests 'feature'." One new issue asked, "Could the app please stop crashing when I upload big
files?" The agent labeled it 'bug'.

Which of these statements uses the word "skill" correctly?

1. The skill is instructions; the 'bug' label was the agent's judgment about the issue.
2. The skill will label every issue the same way each time, since it runs exactly as written.
3. The skill carried out the labeling on its own, with no agent there to follow it.
4. The skill here is the maintainer's knack for spotting bugs, built over years of triage.
