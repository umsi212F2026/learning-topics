# AI agent

### vs-skill

A volunteer organization sorts sign-up forms with an AI agent that follows a skill file,
"sort-volunteers.md". The file says: "Put anyone who mentions children or teaching in the Tutoring
group, and everyone else in General." One form said, "I coached my daughter's soccer team for five
years." The agent put that volunteer in Tutoring, reasoning that coaching children is close to
teaching. The file says nothing about coaching.

In this situation, what is the difference between an AI agent and a skill? Answer in two or three
sentences, in your own words.

### catch-search

A gift shop's AI agent answers customer emails, following a skill file that says, "Offer a refund
when an item arrives damaged." A customer wrote that her mug arrived "a slightly different blue
from the photo", and the agent offered her a refund. The skill file has no other lines about
refunds. A shop worker says:

"An AI agent is just its skill file running, so it can only do what the file says. That refund
must be in the file somewhere; I'll keep searching it."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A university department has an AI agent that books students into professors' office hours,
following a skill file that says, "Never book over a professor's classes." One professor's
calendar showed "Faculty meeting (optional)" at 2 p.m. on Thursday, not a class. The agent left
2 p.m. open anyway, reasoning that she would probably want to attend.

Which of these statements uses the words "AI agent" correctly?

1. The AI agent and its skill file are the same thing, since all it did is written in the file.
2. The AI agent left 2 p.m. open by following an exact rule, the same way a script would.
3. The professor's calendar is an AI agent too, since it is where the agent found the meeting.
4. The AI agent made its own call about 2 p.m., one that its skill file never spelled out.
