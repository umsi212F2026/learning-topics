# Script

### vs-ai-agent

A research lab cleans the survey data that comes in each week. First, a script deletes every row
with no date in it. Then an AI agent reads the free-text comment on each remaining row and tags it
"equipment problem" if the comment seems to describe one.

In this situation, what is the difference between a script and an AI agent? Answer in two or three
sentences, in your own words.

### catch-decided

A web team's workflow ends with a deploy script that runs the tests and, if they pass, puts the
new version of the site live. One afternoon the tests were skipped. A team member writes in the
team chat:

"The deploy script decided to skip the tests this time, because the change looked small."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A small online shop runs a script every night at midnight that copies the day's orders into a
spreadsheet and emails it to the owner. One night an order came in with an emoji in the customer's
name, and the script stopped halfway through the copying. Its instructions say nothing about
emoji.

Which of these statements uses the word "script" correctly?

1. The script chose to stop halfway, judging that the emoji order looked too odd to copy.
2. The script did what its instructions said, and they had no line for an emoji in a name.
3. The script is really an AI agent, since it runs every night without anyone starting it.
4. The whole nightly routine is a script, including the owner reading the email at breakfast.
