Nadia built a workflow on her laptop that reads a bowler's own typed-in scores from one night at the lanes and has an agent, following her skill file, write up that bowler's frame-by-frame stats. Through the model company she uses, a write-up comes to about 2 cents at API prices, which charge by how much text is sent and returned.

The league has about sixty bowlers. Grace bowls with friends about twice a month and would write up each of those nights. She has never paid for a chat subscription, and one would run her $20 a month.

The scores carry nothing but names and pin counts.

Plan A: The league runs the workflow as a web service, BYOK: each bowler gives it their own API key, and the agent step's model calls are billed to that key.

Plan B: Each bowler runs the workflow on their own laptop, with the agent step working under their own subscription to a model company's chat app.
