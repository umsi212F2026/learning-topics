June belongs to a quilting circle of about forty members who swap patterns, and she built a workflow on her laptop for it. A member picks one of the free patterns that quilters post publicly on pattern-sharing sites and says what size of quilt they want, and an agent following June's skill file turns that pattern into a cutting list of every fabric piece. Many of those patterns are posted by their designers with a note asking that they be shared freely.

Members would open it in a web browser, and every member has a phone or a computer that can. The agent step reads only the posted pattern and the chosen size, nothing about the member.

When June tried an open-weight model on ten posted patterns, its cutting lists matched the ones from the model she uses now, piece for piece. The patterns often give sizes in a mix of inches and yards, and one wrong measurement on a cutting list can waste a yard of fabric.

Plan A: June runs the workflow as a web service and pays a model company for the agent step's model calls from June's own account.

Plan B: June runs the workflow as a web service, with the agent step done by an open-weight model on a server June rents.
