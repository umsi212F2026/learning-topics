Ines directs a small nonprofit that helps families find housing, and she built a workflow on her laptop for its grant reports. A coordinator types in their own case notes for the quarter, and an agent following Ines's skill file judges which of the families' outcomes count under the grant's terms and drafts that coordinator's section of the report.

The nonprofit's twelve coordinators would use it, some days from an office computer and some days from home, each with a web browser. The case notes name each family and describe their income and health. When families signed up, they agreed that the nonprofit's staff may read their notes, and they were never asked about any other company seeing them. Ines reads every coordinator's notes as part of her job.

When Ines tried an open-weight model on last quarter's notes, it counted about one outcome in three wrongly, where the model she uses now got nearly all of them right. The grant's terms run to twenty pages, with a different rule for each kind of outcome.

Plan A: Ines runs the workflow as a web service, with the agent step done by an open-weight model on a server Ines rents.

Plan B: Ines runs the workflow as a web service and pays a model company for the agent step's model calls from Ines's own account.
