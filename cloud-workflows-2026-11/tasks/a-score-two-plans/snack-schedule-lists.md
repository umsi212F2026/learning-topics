Alicia built a workflow on her laptop for her town's little league. A family types in their child's food allergies and the games they signed up to bring snacks for, and an agent following Alicia's skill file drafts a snack list for those games that follows the league's snack guide. The allergy notes sometimes name a child's medical conditions.

About ninety families would use it, and every one has a laptop bought within the last few years that can run a small model in its web browser.

Alicia tried two open-weight models on twenty sample families' notes. A small one of the kind that runs in a web browser put a food the child can't eat on about one list in five, while a larger one of the kind a server would run got every list right. The league's snack guide changes each season.

Plan A: Alicia runs the workflow as a web service, with the agent step done by an open-weight model on a server Alicia rents.

Plan B: Alicia runs the workflow as a web page, with the agent step done by an open-weight model that runs in each family's web browser, on their own device.
