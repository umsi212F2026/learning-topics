Ruth built a workflow on her laptop for the town library's volunteers. A volunteer types in the titles of newly arrived children's books, and an agent following Ruth's skill file reads each book's published description and sample pages from the publisher's website and suggests a reading level.

The library has about fifteen volunteers, and each labels a box of books on their weekly shift. Every volunteer has a laptop.

When Ruth tried an open-weight model on last year's books, it gave the wrong level about one time in three, where the model she uses now got nearly all of them right.

Plan A: Ruth runs the workflow as a web service, with the agent step done by an open-weight model on a server Ruth rents.

Plan B: Ruth runs the workflow as a web service and pays a model company for the agent step's model calls from Ruth's own account.
