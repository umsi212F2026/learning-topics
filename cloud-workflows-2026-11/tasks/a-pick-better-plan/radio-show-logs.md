Jo built a workflow on her laptop for the community radio station where she volunteers. After a show, its host types in what they played and said, and an agent following Jo's skill file drafts that show's log for the station's website.

The station has about thirty hosts, and most host one show a week. Theo hosts the weekday morning show and writes a log after each one. On an API key, charged by the amount of text sent and returned, one log comes to about 20 cents. Theo has paid 20 dollars a month for a subscription to a model company's chat app since last spring, mostly for his coursework, and his logs would fit well within its limits.

The show notes sometimes include callers' first names.

Plan A: Jo runs the workflow as a web service, BYOK: each host gives it their own API key, and the agent step's model calls are billed to that key.

Plan B: Each host runs the workflow on their own laptop, with the agent step working under their own subscription to a model company's chat app.
