Lena built a workflow on her laptop for the dog rescue where she volunteers. Someone hoping to adopt types in details of their home, their work hours and their past pets, and an agent following Lena's skill file drafts that person's application and points out what it leaves unanswered.

The rescue expects about a hundred applicants a year, each filling in one application. Applicants often mention their health, their income and their landlord's rules.

When Lena tried a small open-weight model of the kind that runs in a web browser on old applications, it missed about one gap in five. A larger open-weight model on a rented server missed almost none.

Plan A: Lena runs the workflow as a web page, with the agent step done by an open-weight model that runs in each applicant's web browser, on their own device.

Plan B: Lena runs the workflow as a web service, with the agent step done by an open-weight model on a server Lena rents.
