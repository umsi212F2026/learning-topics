The club has about twenty-five members. Mei reads each book in two or three sittings and asks for questions after each one, so about three times a month. On an API key, charged by the amount of text sent and returned, one set of questions comes to about 10 cents. A subscription to a model company's chat app is 20 dollars a month, and Mei has never paid for one and would use it for nothing but the book club.

Every member has a laptop.

Plan A: Each member runs the workflow on their own laptop, with the agent step working under their own subscription to a model company's chat app.

Plan B: Sam runs the workflow as a web service, BYOK: each member gives it their own API key, and the agent step's model calls are billed to that key.
