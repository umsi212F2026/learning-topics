Dana built a workflow on her laptop for her running club. A runner types in their recent runs and the date of their next race, and an agent following Dana's skill file drafts that runner's training plan for the coming week.

The club has about eighty members, and most ask for a new plan each Sunday. On an API key, charged by the amount of text sent and returned, one plan comes to about 4 cents.

Some members' run notes mention their injuries. When Dana tried an open-weight model on old run notes, its plans were often too hard for the runner.

Plan A: Dana runs the workflow as a web service, BYOK: each member gives it their own API key, and the agent step's model calls are billed to that key.

Plan B: Dana runs the workflow as a web service and pays a model company for the agent step's model calls from Dana's own account.

### q1

On cost to Dana, which plan does better?

1. Plan A
2. Plan B
3. They do about as well on cost to Dana
