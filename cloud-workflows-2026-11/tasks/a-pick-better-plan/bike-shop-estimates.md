Hector built a workflow on his laptop for the cycling shop where he works. A mechanic types in their own notes on a bike brought in for repair, and an agent following Hector's skill file drafts a parts list and a price for the customer.

The shop's five mechanics each write several estimates a day.

When Hector tried an open-weight model on last month's notes, about one estimate in four left out a needed part, where the model he uses now left out almost none. The notes include customers' names and phone numbers.

Plan A: Hector runs the workflow as a web service, with the agent step done by an open-weight model on a server Hector rents.

Plan B: Hector runs the workflow as a web service and pays a model company for the agent step's model calls from Hector's own account.
