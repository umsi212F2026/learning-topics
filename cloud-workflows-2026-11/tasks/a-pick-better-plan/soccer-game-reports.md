Priya built a workflow on her laptop for the youth soccer league she helps run. A coach types in notes from their own team's game, and an agent following Priya's skill file drafts a short game report for the team's families.

The league has twenty coaches, and each writes one report after every weekend game. On an API key, charged by the amount of text sent and returned, one report comes to about 3 cents. The league's board has agreed to pay back each coach's API charges every month from the league's budget.

The game notes include the players' first names. When Priya tried an open-weight model on last season's notes, its reports were about as good as the ones she gets now.

Plan A: The league runs the workflow as a web service and pays a model company for the agent step's model calls from the league's own account.

Plan B: The league runs the workflow as a web service, BYOK: each coach gives it their own API key, and the agent step's model calls are billed to that key.
