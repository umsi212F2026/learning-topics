Omar built a workflow on his laptop for his neighborhood newsletter. A neighbor types in an item they want printed, and an agent following Omar's skill file sorts it into one of the newsletter's six sections and fixes its spelling.

About sixty neighbors send in an item or two each month. When Omar tried a small open-weight model of the kind that runs in a web browser on last year's items, it sorted them and fixed their spelling as well as the model he uses now.

Most neighbors have a laptop, and few have ever paid for a chat app.

Plan A: Each neighbor runs the workflow on their own laptop, with the agent step working under their own subscription to a model company's chat app.

Plan B: Omar runs the workflow as a web page, with the agent step done by an open-weight model that runs in each neighbor's web browser, on their own device.
