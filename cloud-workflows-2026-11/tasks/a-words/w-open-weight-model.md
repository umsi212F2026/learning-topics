# Open-weight model

### vs-free-tier

Two model companies make offers to a student club that wants a model for its workflow. Company A lets anyone send up to 50 requests a day to its model at no charge; the model runs only on Company A's servers, and past 50 a day the club would pay. Company B publishes the numbers that make up its model, so the club could download them and run the model on a computer it rents.

Which company offers an open-weight model, and which offers a free tier? Answer in one sentence.

### catch-pick

A book club downloads an open-weight model that a model company published, and runs it on a server the club rents by the month. Members' reading notes go to the model on that server.

Which of these uses the term open-weight model correctly?

1. Because the model is open-weight, members' notes are sent to the company that published it.
2. Because the model is open-weight, the publisher need not see any members' notes.
3. Because the model is open-weight, the club pays nothing at all to run the agent step.
4. Because the model is open-weight, it is as capable as any model a model company sells.
