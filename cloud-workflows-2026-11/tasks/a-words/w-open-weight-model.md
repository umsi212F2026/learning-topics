# Open-weight model

### vs-free-tier

Two model companies make offers to a student club that wants an agent in its workflow. Company A lets anyone send up to 50 requests a day to its model at no charge; the model runs only on Company A's servers, and past 50 a day the club would pay. Company B publishes the numbers that make up its model, so the club could download them and run the model on a computer it rents.

Which company offers an open-weight model?

1. Company A
2. Company B
3. Both
4. Neither

### catch-pick

A book club downloads an open-weight model that a model company published, and runs it on a server the club rents by the month. Members' reading notes go to the model on that server.

Which of these uses the term open-weight model correctly?

1. Because the model is open-weight, members' notes are sent to the company that published it.
2. Because the model is open-weight, the publisher need not see any members' notes.
3. Because the model is open-weight, the club can use it only through the publisher's website.
4. Because the model is open-weight, it is as capable as any model a model company sells.

### catch-pick-2

Volunteers at a free clinic want an agent to sort patients' intake notes, running on a server the clinic rents. They are looking at an open-weight model.

Which of these uses the term open-weight model correctly?

1. Because the model is open-weight, the notes it reads are published for anyone to see.
2. Because the model is open-weight, its publisher sorts the notes free up to a daily limit.
3. Because the model is open-weight, anyone online may send notes to the clinic's copy.
4. Because the model is open-weight, the clinic could download it to run on that server.
