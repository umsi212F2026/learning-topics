# BYOK

### vs-sign-in

Two study services each use a model company's model to summarize lecture notes. Service A asks each new user to create an account and sign in with it; the service then pays the model company for every summary from its own account. Service B asks for no account at all; each user pastes an API key from their own account at a model company into a box, and the service uses that key for that user's summaries.

Which service is BYOK?

1. Service A
2. Service B
3. Both
4. Neither

### catch-pick

A quiz-making service is BYOK: each user pastes in an API key from their own account at a model company, and the service sends that user's requests to the model with it. The service sees each user's notes as it builds their quizzes.

Which of these uses the term BYOK correctly?

1. Under BYOK, each quiz a user makes is billed to that user's own account.
2. Under BYOK, the service pays the model company for every user's quizzes.
3. Under BYOK, no model company sees the notes a user sends for a quiz.
4. Under BYOK, users sign in to the service with their key in place of a password.

### catch-free

A flashcard service makes cards from each user's notes with a model company's model. Its sign-up page says: "Because we're BYOK, you won't need an account at any model company to use our flashcards."

What is wrong with how the sign-up page uses the term BYOK? Answer in one or two sentences.
