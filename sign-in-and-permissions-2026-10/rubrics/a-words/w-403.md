# Rubric: 403

If the learner misses a question here, set a DEFINE or INTERPRET move for 403 live, as help (it is
recorded as helped and doesn't count), then come back to a production question.

403 is the status code for a request from someone signed in but not allowed to do this: the server
knows who is asking and refuses anyway. Its name is Forbidden, a synonym, not a confusable. The
confusables are 401, for a request from someone not signed in, where the server doesn't know who
is asking; and 404, for a request for something the server doesn't have.

### q3

- **goal:** `w-403`
- **move:** CATCH
- **answer:** 403 means the server knows who is asking and is refusing anyway: the second account
  is signed in but not allowed to delete someone else's recipe. Signing in again as the same
  account changes nothing; a session that had run out would have got 401.
- **credit:** full for naming that 403 is for a signed-in user who isn't allowed, so signing in
  again won't help. Half for "that's not what 403 means" without saying what it does mean. None for
  a different quibble alone, such as that sessions should last longer.

### q1

- **goal:** `w-403`
- **move:** DISTINGUISH
- **answer:** A 401 means the request came from someone not signed in, so the server doesn't know
  who is asking. A 403 means the server knows who is asking, because they are signed in, and they
  are not allowed to do this. Signing in can fix a 401; it doesn't fix a 403.
- **credit:** full for naming that 401 is for someone not signed in and 403 for someone signed in
  but not allowed. Half for one side right with the other vague, such as "403 means not allowed"
  with nothing on what 401 means. None for an incidental difference alone, such as the names
  Unauthorized and Forbidden with no account of what each reports.

### q2

- **goal:** `w-403`
- **move:** DISTINGUISH
- **answer:** A 404 means the server has nothing at that address: no such page or no such record.
  A 403 means the thing is there, and the server knows who is asking, but they are not allowed to
  do this to it.
- **credit:** full for naming that 404 is about the thing asked for not being found and 403 about
  the requester not being allowed. Half for "404 is not found" with nothing on what 403 reports.
  None for an incidental difference alone, such as which one browsers show a nicer page for.
- **tutor note:** some apps answer 404 on purpose, to hide that a thing exists from someone not
  allowed to see it. A learner who says so, and still names what each code reports, earns full.
