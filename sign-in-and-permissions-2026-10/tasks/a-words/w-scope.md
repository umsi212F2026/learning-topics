# Scope

Answer in two or three sentences, in your own words, with nothing open in front of you.

### q1

An app lets people sign in through GitHub, and inside the app some users are members and some are
admins. In that app, what is the difference between a scope and a role?

### q2

Pantry, a recipe box for a cooking club, signs members in through GitHub. Club organizers need to
be able to delete any recipe in Pantry. A student says:

"When an organizer signs in, we'll ask GitHub for a bigger scope, so they can delete recipes."

What is wrong with that?

### q3

Pantry shows each member's GitHub name and profile picture, and nothing else from GitHub. Its
agent's plan asks GitHub for the `repo` scope, which covers the user's repositories. A student
says:

"Asking for `repo` is harmless. A scope only changes the wording on GitHub's approval screen; it
doesn't change anything our app can do."

What is wrong with that?
