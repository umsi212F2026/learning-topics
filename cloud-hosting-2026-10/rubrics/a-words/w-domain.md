# Rubric: domain

If the learner misses a question here, set a DEFINE or INTERPRET move for domain live, as help (it
is recorded as helped and doesn't count), then come back to a production question.

A domain is the name people type to reach your app, such as `studyfinder.app`. The confusable is a
URL, the whole address of one particular page or resource, which contains the domain. "Domain
name" means the same as domain and is not a confusable.

### q1

- **goal:** `w-domain`
- **move:** DISTINGUISH
- **answer:** The domain is `studyfinder.app`, the name. The URL is the whole thing,
  `https://studyfinder.app/groups/42`: it adds how to connect (`https://`) and the path to one
  particular page (`/groups/42`). One domain has many URLs, one for each page under it.
- **credit:** full for picking out the domain correctly and saying what separates them: the domain
  is only the name, while the URL is the full address of one page and contains the domain. Half for
  the right domain with nothing on how the URL differs. None for an incidental difference alone,
  such as that a URL is longer or has slashes.

### q2

- **goal:** `w-domain`
- **move:** CATCH
- **answer:** A domain is only a name. Buying it doesn't put the app anywhere: the app is still on
  whatever host runs it, and the name has to be pointed at that host before typing it reaches the
  app.
- **credit:** full for naming that the domain is a name, not a host, so the app is not hosted there
  until the name is pointed at where the app runs. Naming DNS is not required. Half for "they still
  have to set it up" without saying what is missing. None for a different quibble alone, such as
  that `.org` is for nonprofits.
