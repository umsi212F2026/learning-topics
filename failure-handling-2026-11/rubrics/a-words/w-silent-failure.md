# Rubric: Silent failure

If the learner misses a question here, set a DEFINE or INTERPRET move for silent failure live, as help (it is recorded as helped and doesn't count), then come back to a production question.

A silent failure is something going wrong with nothing to say so, so the run looks as if it worked. The reading gives two ways it happens: the step could tell something went wrong but says so only somewhere nobody will look, such as a log nobody reads, or not at all, such as by skipping the item; or the result is wrong but looks right, and nothing checks it. A failure that stops the run with an error a person sees is not silent, however annoying. Being found later by chance doesn't make a failure loud after the fact: what makes it silent is that nothing reported it. The word has no nearest confusable in goals.md, so this bank has no DISTINGUISH question.
