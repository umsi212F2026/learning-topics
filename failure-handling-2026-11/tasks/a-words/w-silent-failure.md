# Silent failure

### catch-pick

Each night, a program copies the recipes Ana saved that day into her meal-planning sheet. Last night she had saved four. One recipe's page wouldn't load, so the program skipped that recipe and went on. The run finished, and the sheet showed three new recipes. Ana noticed the missing one a week later, while looking for it.

Which of these uses the term silent failure correctly?

1. Ana found the gap herself a week later, so it was not a silent failure.
2. Stopping with an error on her screen would also have been a silent failure.
3. Skipping that recipe and saying nothing about it anywhere was a silent failure.
4. Even listing the skip on a page Ana reads daily would leave it a silent failure.

### catch-plant-log

Malik keeps a list of which of his houseplants need water today, and he waters whatever it says. Each morning, an agent reads the readings from his soil sensors and writes that list. Whenever it hits an error, such as a sensor that doesn't answer, it writes the error to a log file. Malik says:

"This step can't have a silent failure, since every error it hits goes into the log."

What is wrong with Malik's claim?

1. Nothing. An error written down somewhere isn't a silent failure.
2. Only a failure that stops the step can be silent, and this one goes on.
3. A log makes errors silent failures only once it's too long to read.
4. Malik reads only the list, so a logged error is still a silent failure.
