Then the judging agent, following a skill file Priya wrote, reads each saved listing and marks its entry 'good with cats' or 'not with cats'. A details program pulls each dog's age and size out of its saved listing and writes them into its entry. A program then flags any entry that has no cat mark, an empty age or an empty size, and puts the flagged entries at the top of the list Priya reads each evening. Each evening she reads the flagged entries and every entry marked 'good with cats', and calls the shelter about any dog that fits.
