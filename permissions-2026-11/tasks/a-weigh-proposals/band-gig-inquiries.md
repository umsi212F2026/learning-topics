Rosa books gigs for her band. Each morning the booking agent, following a skill file Rosa wrote,
runs a download program Rosa wrote, which fetches the new messages sent through the contact form on
the band's website, where anyone can write in, and saves them in a folder called inquiries. The
agent reads each message, checks the date it asks for against the band's calendar file, which Rosa
keeps, and writes a draft reply into a file called replies. Rosa reads every draft and sends the
ones she likes from the band's email account herself. She started the agent in her home folder, so
it runs as her and can read and change every file there, run shell commands and reach the internet.
She set its harness's permission settings to let it run shell commands without asking, so that it
can run the download program. The login for the band's email account, which can read and send the
band's mail, is saved in a settings file in her home folder.

The harm Rosa is worried about: a hidden line in a message makes the agent send the band's email
login to a web address.

Rosa asks her agent what limits could reduce the risk of that harm. It proposes several; each
question below gives one. Each proposal changes only what it names; everything else stays as
described above.

allowlist in its harness's permission settings."
