# Blast radius

### vs-reach

Esi and Dmitri each run a workflow for a different neighborhood association. In each, an agent writes emails to the association's members, and each agent can reach the same things: the whole member spreadsheet and the association's email account. Esi's agent sends each email as soon as it writes it. Dmitri reads and approves every email his agent writes before it is sent.

Which of these is true?

1. Their steps have the same blast radius, since the agents reach the same things.
2. Esi's step has the smaller blast radius.
3. Dmitri's step has the smaller blast radius.
4. Neither step has a blast radius until one of them goes wrong.

### vs-likelihood

A photography club's workflow has two steps done by agents.

- Step A reads members' captions and writes a draft caption list for each show. It often gets a caption wrong. It can change only that draft list, which the organizer checks before any show.
- Step B tidies the club's shared photo archive. In two years it has never gone wrong. It can delete any photo in the archive, and nobody checks what it does.

Which step has the larger blast radius?

1. Step B
2. Step A
3. They are about the same

### catch-never-failed

A small charity has a step in which an agent uploads the week's receipts to the charity's shared drive. The agent can delete every file in the shared drive, and nobody checks what it does. The treasurer says:

"The upload step has never failed in two years, so its blast radius is tiny."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A neighborhood newsletter has an agent write each issue and send it from the newsletter's email account. The agent can read and change every file on the editor's laptop, and each issue goes out without anyone reading it first.

Which of these uses the term blast radius correctly?

1. The step's blast radius is small, since the agent has never made a mistake.
2. The step has no blast radius until something it does actually goes wrong.
3. The editor approving each issue before it goes out would shrink the blast radius.
4. Adding the editor's approval leaves the blast radius as it is, since the reach is unchanged.
