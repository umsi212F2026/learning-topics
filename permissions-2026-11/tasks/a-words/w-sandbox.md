# Sandbox

### vs-read-only

Leila has an agent that summarizes the recipe notes on her laptop. Her blog login is saved in a settings file elsewhere on the same laptop. Her agent proposes two limits she could choose between:

- A: read-only access to every file on the laptop
- B: a sandbox holding only the recipe notes folder

Under which of these could a hidden instruction in a recipe note still get the agent to read Leila's blog login?

1. A only
2. B only
3. Both
4. Neither

### catch-can-change

Marco's agent keeps his band's setlists tidy. It runs in a sandbox that holds only the setlist folder, with the network cut off. Marco says:

"Since it's in a sandbox, it can't change any of my files."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A bike repair shop has an agent draft replies to the repair requests customers send in. The agent runs in a sandbox: a folder holding only the shop's price list and the requests, with no shell commands and no network. The shop's email login is saved in a settings file elsewhere on the laptop.

Which of these uses the term sandbox correctly?

1. The sandbox lets the agent read the price list but not change it.
2. The sandbox keeps the agent from reading the file with the email login.
3. The sandbox stops a customer's request from steering the agent at all.
4. The sandbox makes the agent ask the owner before it opens each file.
