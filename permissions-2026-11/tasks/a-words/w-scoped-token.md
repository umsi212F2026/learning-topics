# Scoped token

### vs-password

Hiro runs a small online shop. A program in his workflow reads each day's new orders from the shop's platform, so it needs a secret saved in its settings file. Hiro could save either of these there:

- his own password for the shop's account
- a scoped token that can read orders and nothing else

Someone copies the secret out of the settings file. With which could they change the shop's prices?

1. Either of them
2. The password only
3. The scoped token only
4. Neither of them

### catch-text-units

Noor has an agent that sorts the emails in her small business's inbox. The agent reads each email in full, and Noor is paying more for it than she expected. She says:

"I'll give the agent a scoped token, so it reads fewer tokens of each email and costs me less."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A tenants' association has an agent post a weekly notice to the association's group page. The agent holds a scoped token for the page that can create posts and do nothing else.

Which of these uses the term scoped token correctly?

1. The scoped token lets the agent post notices, but not remove the page's members.
2. The scoped token is the page's password, so the agent can do whatever an admin can.
3. The scoped token limits how many words of each notice the agent may read.
4. The scoped token keeps the agent from opening other files on its laptop.
