# Human in the loop

### vs-person-trigger

Farah schedules games for a youth soccer league. Each Monday she clicks a button that starts her workflow. An agent then reads the week's field bookings and drafts an email to parents with the game times. Farah reads the draft, fixes anything wrong and approves it, and a program sends it.

#### a

Which term names Farah clicking the button each Monday?

1. Human in the loop
2. A person trigger
3. Neither

#### b

Which term names Farah reading and approving the draft?

1. Human in the loop
2. A person trigger
3. Neither

### catch-after-sending

Gideon edits a hobby club's weekly newsletter. An agent writes each issue and a program sends it to the club's subscribers as soon as it is written. Every Friday, after it has gone out, Gideon reads that week's issue closely. He says:

"I read every issue closely, so I'm the human in the loop."

What is wrong with that? Answer in two or three sentences, in your own words.

### catch-pick

A food bank has an agent draft each week's volunteer schedule from the volunteers' availability, and a program posts the schedule on the food bank's website. The volunteer coordinator starts the run each Friday.

Which of these uses the term human in the loop correctly?

1. The coordinator, by starting each Friday's run, is the human in the loop.
2. A human in the loop would stop the agent reaching files it doesn't need.
3. The coordinator rereading last week's posted schedule is a human in the loop.
4. The coordinator approving each draft before it is posted is a human in the loop.
