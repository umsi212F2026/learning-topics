Hard, `sound-limit`. A club treasurer's reimbursement requests, one step: the ledger agent reads requests anyone who knows the address can send, with nothing narrowing it, and writes each into the ledger with its budget line and whether there is room. The harm comes from untrusted input steering the agent into reach its step doesn't need (the folder of past years' accounts). The proposal is a split: an agent with no reach reads the requests and records only a budget line and a yes or no through a program that accepts nothing else, and the ledger agent, which keeps its reach, reads only those records. It is Hard because the learner has to see that the agent that can delete never sees the requests, and that the agent that sees them can do nothing but record those two things.
