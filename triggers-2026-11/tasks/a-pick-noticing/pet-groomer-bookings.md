groomer's name. Each booking should be confirmed within a few minutes of the owner making it. The
confirmation is a short note with a paw print that our youngest groomer drew.

**About this workflow:** Owners book grooming through the shop's website. The website can send a
message each time a booking comes in. Our computer person can set up the shop
computer, which is never turned off, to take in those messages in an afternoon. Each look at the
bookings means the agent reading through every booking again, which runs up the agent's bill.
