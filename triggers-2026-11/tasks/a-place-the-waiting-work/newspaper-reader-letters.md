the paper's website. In the first quarter hour after each issue goes out, about three hundred letters
arrive, and hardly any come in the rest of the time. The form saves each of those letters as a file
in the newspaper's shared folder. An AI agent on the journalism room's computer reads each letter,
sorts it by topic for the editors, and emails the writer a short thank-you. For each letter it
finishes, the agent adds a line naming that letter to a log. The agent's provider takes only about
ten requests a minute. A thank-you by the end of the school day is soon enough, but every writer
should get one. Our staff is eleven students and one faculty adviser.
