Willow Street Yoga uses an AI agent to fill spots in full classes. When a member cancels a
booking, the agent offers the spot to the next person on that class's waitlist.

**About this workflow:** Cancellations come in a few times a day, at no particular hours. The next
person on the waitlist needs the offer within an hour of a cancellation, or the spot usually goes
unused. Each run has the agent read the whole booking list and every waitlist again, even when
nothing has changed. The agent runs on the studio's front-desk computer, which is never turned
off. The front-desk staff are busy with check-ins and often forget small tasks. The booking page
can send a message to a web address each time someone cancels. The agent can already run itself
at set times, but taking in the booking page's messages would mean the owner setting up something
new, and she finds anything technical a bother. Each offer reaches the waitlisted member by email.
