# Hook

### vs-event-driven

A community garden collects volunteer sign-ups through an online form service. In the form
service's settings, the coordinator entered a web address. Each time someone submits the form, the
form service sends a message to that address, and the coordinator's program adds the new volunteer
to the schedule.

In this workflow, what is the difference between the hook and the workflow being event-driven?
Answer in two or three sentences, in your own words.

### catch-pick

A writer keeps her notes in a git repository. She has set up a git hook so that each time she
makes a commit, a command of hers copies the notes to a backup drive.

In this workflow, what is the hook?

1. The backup drive the notes are copied to
2. Where she told git what to run on each commit
3. A check git makes every few minutes for commits
4. Another name for the backup being event-driven

### catch-weather

A farm wants to know as soon as the weather service issues a storm warning for its county. The
farm manager says:

"We set up a hook on the weather service: every hour our script asks the service whether a storm
warning has been issued."

What is wrong with that? Answer in two or three sentences, in your own words.
