Shape `hook-best`, case `hook`. The natural method is a webhook: the website sends a notice each
time an offer arrives. The source can send word ("The website can send a message to a web address
each time an offer comes in"), receiving it is easy to set up on a machine that is never off ("My
son can easily set up the shop computer, which is never turned off, to take in those messages"),
and the result is needed soon ("Each offer should get an answer within five minutes of the seller
sending it"). Frequent checking is ruled out because the source limits how often it may be looked
at: "The website lets a program look at the list of offers at most once an hour." The neutral
sentence is "The answer is a short note with the owl my sister drew for the sign above our front
door." Two webhook, two polling.

- **tutor note:** Sound (1): the son can easily set up the always-on shop computer to take in the
  website's messages, so each offer arrives as it is sent; that is what separates a webhook from
  polling here. 2 is the other method, checking often enough to be timely: each offer should get an
  answer within five minutes, but the website lets a program look at most once an hour, so a look
  every two minutes isn't allowed. 4 is the other method, checking only as often as allowed: the
  website does limit looks to once an hour, but then an offer can wait up to an hour, far past the
  five minutes. 3 is not a difference: the owl drawing bears on nothing about how new offers
  are found. If the learner picks 2, ask how often the website lets a program look.
