run. The two facts behind it: the website holds every inquiry and can list them by when they came

done ("The agent sends each quote straight out and keeps no copy, so nothing on the laptop shows

Other kinds. A list the workflow keeps is not workable: the laptop is off from 10:30 a.m. to 7

would newly start keeping (the agent writes a line naming each inquiry it has quoted, and the
waiting work is every inquiry on the website not yet in the log) is workable, though more than the
source needs; it counts as naming where the work waits.

What starts the agent: a schedule at a set time between 7 and 10:30 each morning (say 7:15), or
