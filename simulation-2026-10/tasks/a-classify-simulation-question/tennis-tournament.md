This made-up simulation models a weekend tennis tournament at one club: players are drawn into a
bracket and play matches round by round, scored by tennis's rules, until one player is left. It
leaves out the weather: every match in the model is played as scheduled. Its model parameters are
each player's chance of winning a point on their own serve, the number of players in the draw, the
number of sets in a match, and the game score at which a set goes to a tie-break. One trial is one
simulated tournament, and it records who won each match, how many games each match lasted, and how
many games were played in all. Chance is built into its rules: on each point the server wins with
the chance set by the first parameter.

Each question below comes from a different person who wants this simulation to answer one
question. Each question is about this simulation alone.
