# Rubric: Simulation

If the learner misses a question here, set a DEFINE or INTERPRET move for simulation live, as help
(it is recorded as helped and doesn't count), then come back to a production question.

A simulation is running a model of a process on a computer to see what the process would produce.
An experiment runs the real process itself, with real people or things, and watches what happens.
What makes something a simulation is that a description of the process is run, not the process:
doing the real thing on a small scale or for a short time is still an experiment, and looking up
past records, working out a formula, or asking people for their guesses runs nothing at all.

### catch-rope-off

- **goal:** `w-simulation`
- **move:** CATCH
- **answer:** Roping off the galleries and counting real visitors runs the real process, so it is
  an experiment, not a simulation. A simulation would describe how visitors move from room to room
  precisely enough for a computer, and run that description to see how crowded the first room
  gets.
- **credit:** full for naming that the plan runs the real process with real visitors, which makes
  it an experiment or a real-world test, not a simulation; saying what a simulation would do
  instead is welcome but not required. Half for saying a simulation runs on a computer without
  saying why this plan isn't one. None for a
  different quibble alone, such as one Saturday being too few or the ropes annoying visitors.
- **tutor note:** a learner who objects that one Saturday isn't enough has found a real weakness
  of the plan but not the misuse; ask whether anything in it would run on a computer. In everyday
  speech a rehearsal is sometimes called a simulation; this topic's sense is the one the reading
  gives.

### vs-experiment

- **goal:** `w-simulation`
- **move:** DISTINGUISH
- **answer:** An experiment would board real passengers onto a real plane both ways and time them.
  A simulation would describe how passengers walk down the aisle, stow bags and sit, precisely
  enough for a computer, and run that description for each boarding order to see which seats
  everyone sooner.
- **credit:** full for naming that the experiment runs the real process (real passengers, a real
  plane) and the simulation runs a model of the process on a computer. Half for only one side,
  such as "a simulation is done on a computer", without saying what the experiment does. None for
  an incidental difference alone, such as that the simulation is cheaper, faster, or can be
  repeated many times.

### catch-pick

- **goal:** `w-simulation`
- **move:** CATCH
- **type:** mcq
- **answer:** 1
- **credit:** full for 1 only. Choice 1 runs a model of the dock (rules for how trucks arrive and
  get unloaded) on a computer, which is a simulation. Choice 2 uses existing data, and data from
  two docks at that; nothing is run. Choice 3 works the answer out from a formula, which is a
  different way to answer the question, not a run of a model. Choice 4 collects guesses; nothing
  describes the process or plays it out.
- **tutor note:** a learner who picks 3 may think any calculation about the future is a
  simulation; ask what, in choice 3, plays out the trucks' day.
