Kofi collects board games and keeps a list of the forty games he wants most, each entry showing the
game's lowest current price and a buy-or-wait verdict. Every 30 minutes from 8 a.m. to midnight, a
program on his laptop saves the used-game pages of five online shops into a folder. Then the price
agent, following a skill file Kofi wrote, reads the saved pages and, for every game on the game
list, replaces the entry's lowest price with the lowest one it finds today and replaces its verdict
with a new one, since only the current price and verdict matter to Kofi. A run usually takes about
twenty minutes. On evenings when the shops' sites are slow, though, a run takes nearly an hour, so
it is still going when the next one starts. Every Sunday evening Kofi reads the whole game list, all
forty entries, to decide what to buy that week; he never changes or adds anything in it.
