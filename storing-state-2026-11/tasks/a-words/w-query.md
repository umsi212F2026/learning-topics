# Query

### vs-full-scan

Kwame runs a dog-walking business. Every walk goes into a store of records, one per walk, with the
date, the dog, the client, the price and whether the walk has been billed. After several years in
business, the store holds about 30,000 walks.

Each Friday evening, a billing program sends each client a bill for that week's walks that haven't
been billed yet. This month Kwame is moving to new bookkeeping software, and a one-time program
copies every walk in the store, old and new, into it.

#### a

Which term best describes what the copying program needs to do with the store?

1. A query
2. A full scan
3. Neither

#### b

Which term best describes the right way for the billing program to get the walks it bills each
Friday?

1. A query
2. A full scan
3. Neither

### catch-pick

A farm stand keeps a record of every sale from the past several years, about 30,000 rows, each
with the date, the item and the price. At tax time, the owner's program needs the total of last
year's egg sales.

Which of these uses the term query correctly?

1. A query would hand back all 30,000 rows for the program to look through.
2. Adding today's sales to the record is a query, since it changes the record.
3. If the program read all 30,000 rows to pick out the eggs, that would be a query.
4. The program can query the record for just last year's egg sales.

### catch-diary

A runner keeps a training diary in a text file, one short paragraph per day, about 200 entries in
all. To find out how far she ran in March, she scrolls through the whole file from the top and adds
up the distances in the March entries. She tells a friend:

"I ran a query on my diary to get my March total."

What is wrong with that? Answer in two or three sentences, in your own words.
