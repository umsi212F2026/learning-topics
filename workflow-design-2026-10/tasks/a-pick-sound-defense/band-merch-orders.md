Each question gives two people's defenses of the same choice for one step. Pick the sound one.

The Low Tides are a band that sells shirts and records from their website, about 200 orders a
week. The band's manager runs this workflow every week to get the orders packed and shipped.

1. Collect the week's orders, with any message the fan typed in the order's notes box.
   (a program)
2. Read each message and sort it: nothing to do, a change of size or color, a note to go in a
   gift, or a problem with an earlier order. (who?)
3. Go over the sorted messages, fix any that are sorted wrong, and approve the week's packing
   list. (the band's manager)
4. Buy a shipping label for each order on the approved packing list. (who?)
5. Email each fan a tracking number. (a program)

**About step 2:** Its input is about 200 typed messages a week, some a single word and some a
paragraph asking for two changes at once. A mistake here is caught at step 3, where the band's
manager reads every sorted message before anything is packed. Many messages are notes to go in a
gift, and some mention a friend's illness or a death in the family. The week's messages are all in
when orders close on Monday at midnight.

**About step 4:** Its input is the packing list the band's manager approved at step 3, one line per
order with the items and the shipping address. A mistake here sends a package to the wrong place
or pays for the wrong label, and nothing later catches it. It handles each fan's name and home
address. About five lines a week have the whole address typed on the street line, with the city
and postal code left blank. The approved packing list is ready each Wednesday morning.

### q1

Zoe and Marcus both think step 2 should be done by an AI agent rather than a person. Here is how
each puts it.

**Defense 1, Zoe's:** An AI agent rather than a person helps timeliness, because a person would
spend hours each week sorting about 200 messages. It hurts privacy, because gift notes about a
friend's illness or a death go to the agent's provider.

**Defense 2, Marcus's:** An AI agent rather than a person helps timeliness, because the week's
messages are all in when orders close on Monday at midnight. It hurts privacy, because gift notes
about a friend's illness or a death go to the agent's provider.

Which defense is sound?

1. Zoe's
2. Marcus's

### q2

Lena and Theo both think step 4 should be done by a program rather than an AI agent. Here is how
each puts it.

**Defense 1, Lena's:** A program rather than an AI agent helps correctness, because it buys each
label for exactly the address on the approved list. It hurts timeliness, because no label can be
bought before Wednesday morning.

**Defense 2, Theo's:** A program rather than an AI agent helps correctness, because it buys each
label for exactly the address on the approved list. It hurts timeliness, because it has to set
aside the addresses typed all on the street line.

Which defense is sound?

1. Lena's
2. Theo's
