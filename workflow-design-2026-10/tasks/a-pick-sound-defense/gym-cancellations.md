Each question gives two people's defenses of the same choice for one step. Pick the sound one.

Northside Fitness is a gym with about 2,000 members. Its front-desk manager runs this workflow
every week to handle members who want to cancel, about 120 requests a week.

1. Collect the week's cancellation messages from the contact box on the gym's website. (a program)
2. Read each message and sort it: cancel now, cancel when the contract ends, freeze the membership
   instead, or not a cancellation. (who?)
3. Review the sorted messages, fix any that are sorted wrong, and approve the list of
   cancellations. (the front-desk manager)
4. Stop the monthly billing for each cancellation on the approved list. (who?)
5. Email each member a confirmation. (a program)

**About step 2:** Its input is about 120 typed messages a week, written in every style from one line
to a long story. A mistake here is caught at step 3, where the front-desk manager reviews every
sorted message before anything changes. Many of the messages give a health reason for canceling,
such as an injury or a pregnancy.

**About step 4:** Its input is the list the front-desk manager approved at step 3, one line per
member with the date billing should stop. A mistake here charges a member who has canceled, or
stops billing a member who hasn't, and nothing later catches it. It handles each member's name
and saved payment card. About three entries a week arrive with a note typed where the date
belongs, such as "after my last class". The approved list is ready each Friday afternoon.

### q1

Keiko and Omar both think step 2 should be done by an AI agent rather than a person. Here is
how each puts it.

**Defense 1, Keiko's:** An AI agent rather than a person helps timeliness, because the front-desk
manager reviews every sorted message at step 3. It hurts privacy, because the injuries and
pregnancies members mention go to the agent's provider.

**Defense 2, Omar's:** An AI agent rather than a person helps timeliness, because sorting about
120 messages a week, in every style, would take a person hours. It hurts privacy, because the
injuries and pregnancies members mention go to the agent's provider.

Which defense is sound?

1. Keiko's
2. Omar's

### q2

Dana and Luis both think step 4 should be done by a program rather than an AI agent. Here is how
each puts it.

**Defense 1, Dana's:** A program rather than an AI agent helps correctness, because it stops
billing for exactly the cancellations on the approved list. It hurts timeliness, because it has to
set aside the entries with a note where the date belongs.

**Defense 2, Luis's:** A program rather than an AI agent helps correctness, because it stops
billing for exactly the cancellations on the approved list. It hurts timeliness, because it can't
stop any billing before Friday afternoon.

Which defense is sound?

1. Dana's
2. Luis's
